纯前端小工具 · 2026

计时器

  • HTML
  • CSS
  • 原生 JS
  • 单文件

只有三个按钮：开始、暂停、重置。计时用时间戳相减，而不是每秒钟累加， 所以切到别的标签页再回来，秒数依旧准；界面只用圆角、细边和一层柔和阴影。

新窗口打开 ↗

一个 HTML 文件、一段 CSS、一段原生 JS，没有任何依赖，也没有构建步骤。

  • 用时间戳差值计时，切到后台再回来不会漂移
  • requestAnimationFrame 重绘，按钮状态与显示同步
  • 单文件、零依赖，可直接嵌进任何页面
